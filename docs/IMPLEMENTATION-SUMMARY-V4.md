## Material changes

The public experience centres on property discovery, with one consistent property presentation across catalogue, related recommendations and comparison. Optional maps stay off the homepage. Mobile customers can search immediately, filter within a named native dialog, browse vertically, compare two properties and reach enquiry/viewing actions. Property recommendations have their own error boundary, so a failed secondary request cannot erase a valid property or its contact controls.

Unsupported claims were removed rather than replaced with invented facts. Preview listings are explicitly marked and development-only. Missing photography, unconfigured services, failed requests and unavailable records have useful recovery paths. Original operational code and backend security remain preserved; public frontend read-query defects were corrected without schema or RLS changes.
