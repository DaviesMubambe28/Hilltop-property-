# Customer evaluation protocol — not yet executed

Recruit consenting Zambian buyers, tenants, land buyers and investors, including mobile-first users and participants using assistive technology. Start with 5–8 qualitative sessions; this is not a statistically representative sample. Use synthetic contact details and a controlled staging system. Do not submit personal data to competitor websites.

Tasks: (1) find a home matching a stated location and budget; (2) change to a rental search; (3) filter land by area without residential room assumptions; (4) compare two listings on a phone; (5) inspect a gallery; (6) explain price, availability and missing facts; (7) prepare an enquiry and viewing request without sending externally; (8) recover from zero matches and map failure; (9) find investment guidance and estimate costs.

For fair competitive evaluation, counterbalance site order, keep device/network/task constant and distinguish unavailable inventory from usability errors. Record consent, anonymised participant ID, task, device, completion, time, errors, help needed, confidence (1–5), verbatim feedback and evidence path. Stop a task before sending a real enquiry or payment. Do not infer accessibility compliance from one participant.
